# 智学助手 —— 产品需求文档（PRD）

> 项目名称：智学助手（StudyMate）
> 一句话描述：基于 LangChain 的课程知识库问答与出题智能体，覆盖"上传资料 → 智能问答 → 自动出题 → 错题沉淀 → 复习计划"的完整学习闭环。
> 文档版本：v1.0（MVP）
> 更新日期：2026-09-26

---

## 1. 产品概述

智学助手是一款面向个人学习场景的智能学习工具。用户将课程资料（PDF、Word、Markdown、TXT 等）上传后，系统自动完成文档解析、文本切分与向量化，构建课程专属知识库。在此基础上，围绕"学、问、练、测、复"提供五大核心能力：

1. **上传文档**：构建课程知识库；
2. **智能问答**：基于 RAG 检索增强生成，回答可溯源；
3. **自动出题**：按题型、难度、数量自动生成题目（含答案与解析）；
4. **错题本**：答错题目自动沉淀，支持标记掌握与复习；
5. **复习计划**：基于错题与知识库生成个性化复习计划。

核心价值：把静态课程资料，转化为"会回答、会出题、会管错题、会排计划"的 AI 助教。

## 2. 项目背景与目标

### 2.1 背景

- 学生复习时面对大量课件、讲义、教材，检索困难、缺乏针对性练习；
- 通用大模型对私有课程内容不了解，回答容易"幻觉"；
- 错题无法有效沉淀，复习缺乏计划性，导致"学了就忘、错了再错"。

### 2.2 目标

- 打造一个支持 Docker 一键部署、本地化的课程知识库问答与出题工具；
- 通过 RAG 降低大模型幻觉，保证回答与题目"有据可依"；
- 打通"问答 → 出题 → 错题 → 复习计划"闭环，提升学习效果；
- 提供简洁直观的网页界面，降低使用门槛。

## 3. 目标用户

| 用户角色 | 典型场景 | 核心诉求 |
| --- | --- | --- |
| 学生 | 期末复习、课前预习、查漏补缺 | 快速查资料、自动出题、错题管理 |
| 教师 / 助教 | 备课、出卷、答疑 | 基于课件快速出题、辅助答疑 |
| 自学者 | 学习某门公开课或教程 | 整理知识库、自问自答、计划复习 |

## 5. 功能详述（用户故事 + 验收标准）

### F1 上传文档

**用户故事**

> 作为一个学习者，我希望上传课程文档，以便系统自动构建知识库供问答、出题与复习使用。

**验收标准**

```
Given 存在一个课程，且用户选择了本地 PDF/Word/Markdown/TXT 文件
When  用户点击"上传"
Then  系统上传文件、完成解析与向量化，并返回文档信息（含切分块数）
```

```
Given 用户上传了一个文档
When  文档解析与向量化完成
Then  文档状态更新为"已入库"，并显示切分后的文本块数量
```

```
Given 用户上传了不支持格式或超过大小限制的文件
When  用户点击"上传"
Then  系统拒绝上传并提示支持的文件类型与大小限制
```

### F2 智能问答

**用户故事**

> 作为一个学习者，我希望向课程知识库提问，以便获得基于课程资料、带出处依据的准确回答。

**验收标准**

```
Given 某课程知识库已构建（包含若干文档）
When  用户在该课程下输入问题并提交
Then  系统先检索知识库中最相关的文本片段，再结合大模型生成回答
```

```
Given 系统生成了回答
When  回答基于检索到的文档片段
Then  回答下方展示引用来源（文档名 + 片段摘要）
```

```
Given 知识库为空（课程下没有文档）
When  用户提问
Then  系统返回友好提示，引导用户先上传文档
```

### F3 自动出题

**用户故事**

> 作为一个学习者，我希望基于课程知识库自动生成题目，以便进行针对性自测。

**验收标准**

```
Given 某课程知识库已构建
When  用户设置题型（单选/多选/判断/简答）、难度（易/中/难）、数量并提交
Then  系统基于知识库内容生成对应数量和题型的题目，含答案与解析
```

```
Given 系统生成了客观题
When  题目返回
Then  客观题以结构化格式返回（题干、选项、正确答案、解析）
```

```
Given 用户请求的题型为"简答"
When  系统生成简答题
Then  每道简答题附带参考答案要点
```

### F4 错题本

**用户故事**

> 作为一个学习者，我希望答错的题目能自动进入错题本，以便集中复习薄弱点。

**验收标准**

```
Given 一批客观题已生成且用户作答
When  用户提交答案且存在答错的题目
Then  系统将答错题目自动加入错题本，记录用户答案与正确答案
```

```
Given 错题本中已有错题
When  用户查看错题本
Then  按课程分组展示错题，显示题干、用户答案、正确答案与解析
```

```
Given 某道错题已被用户掌握
When  用户点击"标记掌握"
Then  该错题状态更新为"已掌握"，不再出现在待复习列表
```

### F5 复习计划

**用户故事**

> 作为一个学习者，我希望基于错题与知识库生成复习计划，以便按计划巩固薄弱知识点。

**验收标准**

```
Given 某课程存在错题或知识库内容
When  用户发起"生成复习计划"
Then  系统基于错题与知识库生成复习计划，含若干条按日期安排的复习条目
```

```
Given 复习计划已生成
When  用户查看计划
Then  以日期分组展示待复习条目，可查看对应题目与知识点
```

```
Given 用户完成了某条复习任务
When  用户点击"标记完成"
Then  该条目状态更新为"已完成"
```

## 6. 界面设计要求

- **整体风格**：简洁清爽，白底 + 蓝色系主色调，教育工具风格；
- **布局**：左侧为课程列表与导航（问答 / 出题 / 错题本 / 复习计划），右侧为主内容区；
- **课程选择**：侧边栏可切换当前课程；
- **问答页**：聊天式布局，用户问题与 AI 回答分区展示，引用来源以卡片内联在回答下方；
- **出题页**：表单（题型 / 难度 / 数量）+ 题目卡片列表，客观题可点击选项作答并即时判分；
- **错题本页**：错题卡片列表，展示正误答案对比，支持"标记掌握"；
- **复习计划页**：以日期/时间轴展示复习条目，支持勾选完成；
- **反馈**：上传、生成等耗时操作展示 loading 状态；
- **响应式**：优先适配桌面浏览器（Chrome / Edge）。

## 7. 技术栈建议

| 层次 | 技术 | 说明 |
| --- | --- | --- |
| 后端框架 | FastAPI + Uvicorn | 轻量、异步、自动生成 OpenAPI 文档 |
| 语言 | Python 3.11 | 语言与运行时版本 |
| AI 框架 | LangChain | RAG 编排、文档加载、切分、向量库、Prompt 模板 |
| 业务数据库 | MySQL 8.0 | 存储课程、文档、题目、错题本、复习计划等结构化数据 |
| 向量数据库 | Chroma | 轻量级本地持久化向量库，无需额外容器 |
| 大模型 | 硅基流动（SiliconFlow）OpenAI 兼容接口 | LLM（DeepSeek-V4-Flash）+ Embedding（BAAI/bge-m3） |
| 前端 | 原生 HTML + CSS + JavaScript | 无框架依赖，静态页面 + fetch 调用后端 API |
| 部署 | Docker + docker-compose | 一键启动 MySQL、Backend（Chroma本地持久化） |

## 8. 非功能性需求

### 8.1 性能

- 单文档（≤ 10MB）上传到向量化完成尽量 ≤ 30 秒；
- 问答与出题需有 loading 反馈，MVP 不强制流式；
- 检索召回默认 top_k = 4，可配置。

### 8.2 安全

- API Key、Base URL 等敏感信息通过 `.env` 读取，不硬编码、不提交仓库；
- 上传文件校验类型与大小（白名单 + 上限）；
- 数据库操作使用 ORM 参数化查询，防止 SQL 注入；
- 前端对用户输入做基本转义，防止 XSS。

### 8.3 兼容性

- 后端运行环境：Python 3.11；
- 浏览器：最新版 Chrome / Edge；
- 部署环境：支持 Docker（Linux 内核容器）与本地开发。

### 8.4 可维护性

- 代码分层清晰（路由 / 服务 / 模型 / Schema 分离）；
- Prompt 模板独立维护，业务逻辑与配置解耦。

## 9. 边界场景说明

| 场景 | 处理方式 |
| --- | --- |
| 课程下无文档时提问/出题 | 返回友好提示，引导先上传文档 |
| 上传不支持的格式 | 拒绝并提示支持的文件类型 |
| 上传空文件 / 超大文件 | 校验后拒绝，提示原因 |
| 文档解析失败 | 文档状态标记为"失败"，返回错误信息，不影响其他文档 |
| 生成题目时知识库内容不足 | 返回提示，说明可生成数量不足并尽量生成 |
| 大模型接口异常 / 超时 | 返回统一错误响应，前端提示稍后重试 |
| 答题时题目不存在 | 返回 404 提示 |
| 复习计划无错题可排 | 返回提示，说明缺少可复习内容 |
| 删除课程 | 级联删除其文档、题目、错题、复习计划与向量数据 |
