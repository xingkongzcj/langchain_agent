# 人工智能与 LangChain 学习笔记

## 一、人工智能概述

人工智能（Artificial Intelligence，简称 AI）是一门让机器模拟人类能力的技术科学。
简单来说，就是赋予机器人类的思维、学习、判断和问题解决能力，让机器不再只是被动执行固定命令，
而是可以自主感知、理解、思考和迭代优化。

AI 的核心目标有三个：
1. 模仿人类思维：让机器看懂图像、听懂语言，具备逻辑推理能力。
2. 解决复杂问题：在海量数据中发现人类肉眼无法察觉的规律。
3. 自主适应环境：让机器能从经验中学习并改进。

## 二、AI 发展四大阶段

### 第一阶段：规则时代（1950s - 1980s）

核心思想是人工编写固定规则，机器没有学习能力。
代表性事件是 1956 年达特茅斯会议，麦卡锡首次提出"人工智能"术语。

局限：缺乏灵活性，规则永远写不完。

### 第二阶段：机器学习（1990s - 2010s）

核心思想是不再人工编写规则，而是给机器海量数据，让机器自主挖掘数据规律。
代表性算法包括 SVM、KNN 等。

局限：特征工程成本极高，复杂逻辑任务无力支撑。

### 第三阶段：深度学习（2010s - 2017）

核心思想是用多层神经网络模拟人脑的层级处理机制。
代表性事件是 2012 年 AlexNet 夺冠、2016 年 AlphaGo 击败李世石。

局限：一个模型只能搞定一类任务，依赖大量标注数据。

### 第四阶段：大模型时代（2017 - 至今）

核心突破是 2017 年 Transformer 架构诞生。
大模型 = 海量数据 + 超大参数规模 + Transformer 架构 + 自监督学习。

代表性事件：
- 2018 年 BERT、GPT 系列模型问世
- 2020 年 GPT-3（1750 亿参数）诞生
- 2022 年 ChatGPT 上线

## 三、大模型的三大局限

1. 知识滞后：训练数据存在固定截止日期，无法获取实时信息。
2. 知识缺失：无法获取私有、专属、垂直领域数据。
3. 模型幻觉：无依据编造事实，一本正经地胡说八道。

解决幻觉问题最主流的技术路径是 RAG（检索增强生成）和微调。

## 四、什么是 RAG

RAG（Retrieval-Augmented Generation，检索增强生成）是一种将信息检索与大模型文本生成
结合的技术。简单理解，就是给大模型外挂一个外部知识库，让它从"闭卷瞎编"变成"开卷考试"。

RAG 的核心逻辑分三步：
1. 检索：根据用户提问，从私有知识库中精准召回相关资料片段。
2. 增强：将检索到的专属资料注入提示词，为大模型补充作答依据。
3. 生成：大模型结合检索资料与自身能力，输出精准、合规、有据可依的答案。

RAG 的优点是无需重新训练模型，低成本实现知识更新，保护数据隐私。
缺点是响应时延更高，Token 消耗更大。

## 五、什么是 LangChain

LangChain 是 2022 年 10 月由哈佛大学开发者 Harrison Chase 发起并开源的大语言模型应用开发框架。

LangChain 的核心定位是衔接大语言模型与上层 AI 应用的中间层开发框架，解决三个问题：
1. 打通内外资源：统一接口对接各类大模型、数据库、API。
2. 封装底层复杂度：抽象工具调用、上下文管理、记忆机制。
3. 支撑规模化协作：支持从单智能体拓展至多智能体协作。

LangChain 的核心组件包括：
- Models：模型接口
- Messages：消息交互单元
- Prompts：提示词模板
- Chains：链式编排
- Agents：智能体编排
- Tools：外部能力封装
- Memory：记忆管理
- Retrievers：信息检索
- Vector Stores：向量存储

## 六、什么是智能体 Agent

AI 智能体是基于大语言模型作为核心大脑，融合感知、记忆、推理规划、工具调用、
自省纠错能力，能够自主感知信息、决策行动、独立完成复杂任务的系统。

智能体的四大核心要素：
1. 大脑：大语言模型，负责推理、理解、决策。
2. 记忆：模拟人类记忆机制，包括短期记忆和长期记忆。
3. 工具调用：让智能体拥有落地实操能力。
4. 规划决策：将复杂目标转化为可执行的子任务。

智能体与传统大模型的区别：
- 传统大模型：被动响应，一问一答，只能告诉你"如何做"。
- 智能体：主动推进，自主闭环，能直接帮你"做完"。

## 七、FastAPI 简介

FastAPI 是一个现代、快速（高性能）的 Web 框架，基于 Python 类型注解构建。
它完全支持异步编程，原生支持 Pydantic 数据校验，自动生成 OpenAPI 文档。

FastAPI 的核心特性：
- 快速：性能可与 NodeJS 和 Go 并肩。
- 高效编码：提高功能开发速度约 200% 至 300%。
- 更少 bug：减少约 40% 的人为错误。
- 自动文档：自动生成交互式 API 文档（Swagger UI 和 ReDoc）。

FastAPI 的三大核心参数：
1. 路径参数：传递唯一标识，写在 URL 路径中。
2. 查询参数：分页、筛选，拼接在问号后面。
3. 请求体参数：传递复杂表单数据，通过 Pydantic 模型校验。

## 八、Chroma 向量数据库

Chroma 是一个轻量级的开源向量数据库，API 极简，适合开发测试和原型验证。

Chroma 的核心特点：
- 轻量级：无需额外服务，本地文件持久化。
- 开源免费：Apache 2.0 协议。
- API 简洁：几行代码即可完成向量存储和检索。
- 与 LangChain 深度集成：langchain-chroma 提供官方支持。

Chroma 的使用流程：
1. 初始化 Embedding 模型（如 BAAI/bge-m3）。
2. 准备文档列表。
3. 调用 Chroma.from_documents() 写入向量库。
4. 使用 similarity_search() 检索相似文档。
